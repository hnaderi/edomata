# API reference

The API documentation of every crate is generated by `rustdoc` from the sources of the `main` branch and deployed with the website, next to this book. It documents the public items, with examples that are compiled and run as doc tests.

**[Browse the API documentation](https://beyond-scale-group.github.io/edomata/rust/api/)**

| Crate | API documentation | Contents |
|-------|-------------------|----------|
| `edomata-core` | [`edomata_core`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_core/) | `Decision`, `DecisionT`, `ResponseT` (`ResponseD`, `ResponseE`), `Action`, `Edomaton`, `Stomaton`, the DSLs, `DomainModel`, `CqrsModel`, messages, `syntax` |
| `edomata-backend` | [`edomata_backend`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_backend/) | `eventsourcing` and `cqrs` backends and builders, storage traits, `inmemory` driver, `Codec`, caches, outbox, `BackendError`, `retry` |
| `edomata-postgres` | [`edomata_postgres`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_postgres/) | `PGNaming`, `PGNamespace`, `PGSchema`, `EventMigration` |
| `edomata-serde` | [`edomata_serde`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_serde/) | `SerdeCodec`, PostgreSQL wire types, Scala compatibility helpers |
| `edomata-sqlx` | [`edomata_sqlx`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_sqlx/) | `SqlxDriver`, `SqlxCqrsDriver`, `SqlxCodec`, `SqlxHandler`, `SqlxMigrations` |
| `edomata-testkit` | [`edomata_testkit`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_testkit/) | `EdomatonAssertions`, `StomatonAssertions`, `TestCommand` |
| `edomata-saas` | [`edomata_saas`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_saas/) | tenancy types, `AuthPolicy`, guards, guarded DSLs and services, readers, `SaaSPGSchema` |
| `edomata-saas-sqlx` | [`edomata_saas_sqlx`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_saas_sqlx/) | `SaaSSqlxCqrsDriver`, `SaaSCodec`, `TenantStateLister` |
| `edomata-simple` | [`edomata_simple`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_simple/) | `SimpleBackend`, `SimpleDecision`, `AppResult`, `CommandHandler`, `SimplePGSchema` |

| `edomata-e2e` | [`edomata_e2e`](https://beyond-scale-group.github.io/edomata/rust/api/edomata_e2e/) | end-to-end domain and the cross-language test (test-only) |

To build the same documentation locally, with the Rust sources of the repository:

```sh
cd rust
cargo doc --workspace --all-features --no-deps --open
```
