# ADR 0006: PostgreSQL naming, DDL generation and golden files

- Status: accepted
- Date: 2026-09-25
- Milestone: 3 (Postgres DDL)

## Context

`modules/postgres` holds the pure PostgreSQL pieces shared by the Skunk and
Doobie drivers: the validated `PGNamespace` opaque type (with a compile-time
macro constructor), the `PGNaming` strategies, `PGSchema` DDL generation and
`EventMigration`. The plan makes the generated DDL a hard wire-compatibility
requirement: byte-for-byte identical to Scala for both naming strategies and
every payload type, asserted against golden files produced by the Scala code.

## Decisions

1. **`PGNamespace` validates at runtime.** Rust has no equivalent of Scala's
   inline macro without a proc-macro crate. `PGNamespace` is a newtype with
   `TryFrom<&str>` / `FromStr` / `from_string` applying the same rule
   (`[A-Za-z_][A-Za-z_0-9$]*`, at most 63 characters) and producing the same
   error messages, without a regex dependency. Invalid names are rejected
   when the naming is built, which is still before any SQL is run.

2. **`PGNaming` is an enum** (`Schema`, `Prefixed`) with the same methods;
   `schema_str` / `prefixed_str` replace the string-literal overloads.

3. **DDL statements are public building blocks.** `edomata_postgres::ddl`
   exposes `schema_statement` and each `*_statements` function so that the `sqlx` driver's automatic
   setup and the generated migrations come from the same source. Payload
   types are spliced verbatim, as in Scala.

4. **Golden files are generated by Scala, not hand-written.**
   `modules/postgres/src/test/scala/GoldenDDL.scala` (test scope, the only
   Scala addition allowed by the plan for this purpose) writes one file per
   naming × payload-type case: statements joined by `\n` plus a trailing
   newline. `tests/golden.rs` mirrors the case list, compares whole files
   with `assert_eq!` and checks that no golden file is left uncovered. The
   cases include a mixed-case namespace containing `$` to exercise quoting.

5. **`EventMigration` keeps its shape**: version, description and an `Arc`-shared
   `Fn(&str) -> Result<String, String>`; `typed` replaces the generic
   factory (the exhaustiveness guarantee comes from Rust `match`), and
   `and_then` composes with the same "take the next version" rule. The
   runner (`migrations` table, batching, snapshot truncation) belongs to the
   `sqlx` driver.

## Consequences

- Changing `PGSchema.scala` requires regenerating the golden files (command
  in `CLAUDE.md`); the Rust test then fails until `schema.rs` is aligned.
- `SaaSPGSchema` (RLS policies) is covered the same way in milestone 6.
